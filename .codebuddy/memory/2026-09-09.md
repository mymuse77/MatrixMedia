# 2026-09-09

## 修复 npm run dev 报 Cannot find module 'ajv/dist/compile/codegen'

- 现象：`ajv-keywords@5.1.0`（需 ajv@8）被提升到顶层 `node_modules`，向上解析到顶层 `ajv@6.x`，缺少 `dist/compile/codegen`。
- 根因：`node_modules` 是 pnpm 安装且**上次安装被中断**的损坏混合态（有 `ajv_tmp_2440_1059`、`json-schema-traverse_tmp_2440_1060` 残留目录），顶层 ajv=6.15.0、ajv-keywords=5.1.0 且无嵌套 ajv@8。
- 处理：删除 `node_modules` 后 `npm ci`（严格按 package-lock.json），npm 得到正确嵌套：`node_modules/ajv`=6.12.6（eslint用）、`node_modules/schema-utils/node_modules/ajv`=8.17.1 + `ajv-keywords`=5.1.0。

## 重要纠正：nodeLinker: hoisted 是错误方向

- 昨天（09-08）为修 electron-builder 打包漏 express 传递依赖而加的 `nodeLinker: hoisted` **已撤销**。
- 原因：hoisted 即扁平化，必然引发 ajv 6/8 冲突，破坏 dev。
- 正确结论：**改用 npm**。npm 的嵌套结构 electron-builder 原生支持最好，能同时解决 dev 的 ajv 冲突和打包漏依赖问题。

## 项目环境事实

- 项目同时存在 `package-lock.json` / `yarn.lock` / `pnpm-lock.yaml` 三个锁文件，`package.json` 无 `packageManager` 字段。当前统一走 **npm**。
- `.npmrc` 保留 `registry` / `electron_mirror` / `electron_builder_binaries_mirror`（electron install.js 会读取 electron_mirror，npm 的 unknown config 警告可忽略）。
- Node.js v24.14.0，electron 21.4.4。
- `pnpm-workspace.yaml` 仅保留 `allowBuilds` 白名单（供 pnpm 使用时生效）。
